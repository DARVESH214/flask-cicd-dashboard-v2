# Flask CI/CD Dashboard

## 🚀 Project Overview

This project demonstrates an end-to-end DevOps workflow using Flask, GitHub Actions, Docker, Docker Hub, and AWS EC2.

The application is automatically built and tested through a CI pipeline, containerized using Docker, published to Docker Hub, and deployed on AWS EC2.

---

## 🏗️ Architecture

Developer → GitHub Repository → GitHub Actions → Docker Image → Docker Hub → AWS EC2 → Live Application

---

## ✨ Features

- Flask Web Application
- Automated CI Pipeline using GitHub Actions
- Docker Containerization
- Docker Hub Integration

---

## 🔄 CI/CD Workflow

1. Push code to GitHub
2. GitHub Actions workflow is triggered
3. Application is tested and built
4. Docker image is created
5. Docker image is pushed to Docker Hub
6. Application is deployed on AWS EC2
